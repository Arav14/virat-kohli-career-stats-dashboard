# Virat Kohli Career Statistics Analysis Dashboard (Power BI)

Power BI dashboard analyzing Virat Kohli's international batting career
from 2008 to 2026 across Test, ODI and T20I formats
(28,215 runs across 625 innings).

## Tools
Power BI Desktop, Power Query, Google Sheets

## Data
`kohli_career_stats.csv`: year-wise stats per format: innings, runs, balls,
outs, average, strike rate, highest score, 50s, 100s, 4s, 6s and dot-ball %.

## What I did
- Connected Power BI to a Google Sheets source and cleaned it in Power Query
- Built 4 KPI cards: Innings, Runs, Average, Strike Rate
- Added Format and Year Range slicers to filter the whole dashboard
- Built a Runs by Year column chart, a Boundaries (4s vs 6s) donut chart
  and a 50s/100s area chart

## How to use
Download the `.pbix` file and open it in Power BI Desktop.
Use the Format and Year slicers to explore each phase of his career.
